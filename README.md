# 📊 บันทึกรายได้เทรด XAUUSD (XAUUSD Income Journal)

เว็บแอปสำหรับบันทึกรายได้/รายจ่ายจากการเทรดทอง XAUUSD
**คำนวณด้วยสูตรเดียวกับใบบันทึกในรูปที่ให้มา** — ใช้งานออฟไลน์ เก็บข้อมูลไว้ในเครื่อง (localStorage) ไม่ต้องติดตั้งอะไร

---

## 🧮 สูตรการคำนวณ (ตรงกับใบบันทึกเดิมทุกตัวเลข)

| คอลัมน์ | สูตร | ตัวอย่างจากใบบันทึก |
|---|---|---|
| **US$** | กำไร/ขาดทุนขั้นต้น (หน่วยตามใบบันทึก) | 18,352.00 |
| **−30%** | `US$ × อัตราคอมมิชชัน` | 5,505.60 |
| **US$ TOTAL** | `US$ − คอมมิชชัน` | 12,846.40 |
| **USD TOTAL** | `US$ TOTAL ÷ ตัวหาร (100)` | 128.46 |
| **Daily THB** | `USD TOTAL × อัตราแลกเปลี่ยน (33.00)` | 4,239.31 |

กล่องสรุปด้านบนของใบบันทึก:

| กล่อง | สูตร | ตัวอย่าง |
|---|---|---|
| **Total (THB)** | `ผลรวม Daily THB` | 91,110.79 |
| **Commission (THB)** | `(ผลรวมคอมมิชชัน ÷ 100) × อัตราแลกเปลี่ยน` | 39,047.48 |

> หมายเหตุเรื่องหน่วย: คอลัมน์ `US$` ในใบบันทึกเดิมเป็น **เซนต์ (¢)** — หารด้วย 100 จึงได้ USD จริง
> (เช่น 18,352 เซนต์ = 183.52 USD → สุทธิ 128.46 USD → 4,239.31 THB ที่อัตรา 33)
> แอปตั้งค่าเริ่มต้นเป็นหน่วยเซนต์ จึงให้ผลลัพธ์ตรงกับใบบันทึกทุกแถว

## ✨ ความสามารถ

- **ตารางบันทึก** คอลัมน์เดียวกับใบบันทึกเดิม พร้อมแถวรวมยอด (Total) ด้านล่าง
- **กราฟ** แท่งรายวัน (Daily THB) + เส้นยอดสะสม
- **2 วิธีบันทึก**
  - จาก **ราคาเข้า/ราคาออก + จำนวนล็อต** (คำนวณ P/L ตามขนาดสัญญา XAUUSD 100 ออนซ์/ล็อต ให้อัตโนมัติ)
  - **กรอกกำไรเอง** ตามหน่วยในใบบันทึก
- **ตั้งค่าได้**: อัตราแลกเปลี่ยน, ค่าคอมมิชชัน %, ตัวหาร, หน่วย (เซนต์/ดอลลาร์), ขนาดสัญญา
- **กรอง**: ตามเดือน / ค้นหา / เฉพาะวันที่มียอด
- **เรียงวันที่**: วันที่ล่าสุดอยู่แถวแรก (ค่าเริ่มต้น) — กดปุ่ม `⇅` ในแถบเครื่องมือเพื่อสลับเป็นเก่าสุดก่อน
  (กราฟยังเรียงตามเวลาจากซ้ายไปขวาเสมอ)
- **เติมวันที่ว่างอัตโนมัติ** (ข้ามเสาร์–อาทิตย์ได้) ให้ตารางครบทุกวันเหมือนใบบันทึก
- **นำเข้า/ส่งออก CSV** (เปิดกับ Excel ได้, มี BOM รองรับภาษาไทย) — ย้ายข้อมูลจากใบบันทึกเดิมได้ทันที
- **สำรอง/กู้คืนข้อมูล JSON** — กันข้อมูลหาย (สำคัญบน iPad) และย้ายข้อมูลระหว่างเครื่องได้
- **ใช้บน iPad ได้** — หน้าจอปรับตามขนาด, ปุ่มขนาดนิ้วกด, เพิ่มลงหน้าจอโฮมได้ (ไอคอน + โหมดเต็มจอ)
- **สรุป**: Total (THB), Commission (THB), US$ TOTAL, USD TOTAL, จำนวนวันเทรด, Win rate
- ข้อมูลถูกเก็บในเครื่องอัตโนมัติ (localStorage) — ปิดเบราว์เซอร์แล้วก็ยังอยู่

## 📱 เปิดบน iPad / แท็บเล็ต

แอปนี้เป็นเว็บล้วน (ไม่มี backend) จึงเปิดบน iPad ได้เลย — เลือกวิธีใดวิธีหนึ่ง

### วิธีที่ 1: เปิดจากเครื่อง Mac ในวง Wi-Fi เดียวกัน (แนะนำ)

```bash
python3 tools/dev-server.py 5173
```

จะแสดง URL ให้ 2 แบบ เช่น

```
เครื่องนี้        :  http://localhost:5173/index.html
iPad / มือถือ     :  http://MacBook-Pro.local:5173/index.html   ← แนะนำ (ที่อยู่คงที่)
ทาง IP            :  http://192.168.1.23:5173/index.html
```

1. ต่อ iPad ให้อยู่ **Wi-Fi วงเดียวกับ Mac**
2. เปิด URL แบบ `.local` ใน **Safari** (ที่อยู่จะไม่เปลี่ยนแม้ IP เปลี่ยน ทำให้ข้อมูลไม่หาย)
3. ถ้า macOS เด้งถาม firewall ให้กด **Allow**
4. **เพิ่มลงหน้าจอโฮม** เพื่อให้เปิดได้เหมือนแอปจริง: Safari → ปุ่มแชร์ → *เพิ่มไปที่หน้าจอโฮม*
   (จะมีไอคอนทอง "Au" และเปิดแบบเต็มจอ ไม่มีแถบเบราว์เซอร์)

> ถ้าเปิดไม่ได้ ให้เช็ค: Wi-Fi วงเดียวกัน, firewall ของ macOS, และ `ping <ชื่อเครื่อง>.local` จากอุปกรณ์อื่น

### วิธีที่ 2: เปิดลิงก์ออนไลน์ (ไม่ต้องเปิด Mac ค้างไว้)

ใช้ **https://monthol22.github.io/xauusd-journal/** จากอุปกรณ์ใดก็ได้ — ดูหัวข้อ
[🌍 ใช้งานได้ทุกที่](#-ใช้งานได้ทุกที่-ออนไลน์แล้ว) ด้านบน

### ⚠️ เรื่องที่ควรรู้บน iPad

- **ข้อมูลเก็บแยกตามเครื่อง/เบราว์เซอร์** — Mac กับ iPad จะมีข้อมูลคนละชุด
  ย้ายข้อมูลด้วย **💾 สำรองข้อมูล (JSON)** แล้วกด **♻️ กู้คืนข้อมูล** บนอีกเครื่อง (หรือใช้ CSV)
- Safari อาจล้าง localStorage ถ้าไม่ได้เปิดแอปเกิน ~7 วัน — **ควรกดสำรองข้อมูลเป็นระยะ**
  (ถ้าเพิ่มลงหน้าจอโฮมแล้วจะเก็บได้เสถียรขึ้น)
- ต้องใช้ **iPadOS 14 ขึ้นไป** (แอปใช้ BigInt ในการคำนวณเงินให้แม่นระดับสตางค์)

assets/styles.css      สไตล์
assets/icon-*.png      ไอคอนแอป (180/192/512)
tests/calc.test.mjs    เทสต์เทียบกับตัวเลขในใบบันทึก

tools/publish.sh       build แล้ว push ขึ้น GitHub Pages

## 📥 นำเข้าข้อมูลจากใบบันทึกเดิม (Excel)

1. เปิดไฟล์ Excel → บันทึกเป็น **CSV UTF-8**
2. ในแอปกด **⬆️ นำเข้า CSV**
3. แอปจะอ่านคอลัมน์ `วันที่` และ `US$` อัตโนมัติ (รองรับชื่อคอลัมน์ภาษาไทย/อังกฤษ)
   ถ้ามีคอลัมน์ `ราคาเข้า / ราคาออก / ล็อต` แอปจะคำนวณกำไรให้เอง
   หากต้องการค่าเป็น **USD จริง** ให้เปลี่ยนหน่วยในตั้งค่าเป็น "ดอลลาร์" ก่อนนำเข้า
